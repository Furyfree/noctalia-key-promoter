# Key Promoter for Hyprland + Noctalia

A Noctalia plugin that shows the Hyprland shortcut when you open an app from
the launcher or switch workspace by clicking the bar. See
[key-promoter/README.md](key-promoter/README.md) for usage and settings.

## Install

Add this repo as a plugin source and enable the plugin:

```sh
noctalia msg plugins source add furyfree git https://github.com/Furyfree/noctalia-key-promoter
noctalia msg plugins enable furyfree/key-promoter
```
